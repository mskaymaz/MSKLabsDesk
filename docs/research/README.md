# Araştırmalar ve Teknik İncelemeler (`docs/research/`)

Harici servis değişiklikleri, altyapı/kota denetimleri, üçüncü parti API güncellemeleri ve teknik fizibilite incelemeleri bu dizinde arşivlenir.

## Dosya İsimlendirme ve Format Standardı
* **Dosya Adı:** `YYYY-AA-GG_kisa_konu_basligi.md` (Örn: `2026-11-25_google_workspace_api_etki_analizi.md`)
* **Zorunlu Başlıklar:**
  1. **Özet ve Bağlam:** İncelemenin nedeni, tarih ve kapsam.
  2. **Teknik Bulgular:** Doğrudan CLI/API/kod üzerinden doğrulanan somut veriler.
  3. **Etki Değerlendirmesi:** Mevcut ürün ve altyapılara etkisi.
  4. **Karar ve Sonraki Adımlar:** Alınan karar, aksiyon gerekip gerekmediği ve varsa kontrol tarihleri.

## İndeks
